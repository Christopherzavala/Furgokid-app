## Bucket y permisos

El flujo usa la API oficial de Firebase `projects.getDefaultBucket` y contrasta el número de proyecto con metadatos de Cloud Storage, en vez de asumir que el nombre acaba en `appspot.com`. La ubicación se registra en la validación; esta fase no decide una región jurídicamente adecuada. La comprobación previa de permisos consulta `storage.objects.create`, `storage.objects.get` y `storage.objects.list` y aborta si falta cualquiera.

- [Firebase `projects.getDefaultBucket`](https://firebase.google.com/docs/reference/rest/storage/rest/v1alpha/projects/getDefaultBucket)
- [Firebase recurso `DefaultBucket`](https://firebase.google.com/docs/reference/rest/storage/rest/v1alpha/projects.defaultBucket)
- [Cloud Storage: obtener metadatos de bucket](https://docs.cloud.google.com/storage/docs/json_api/v1/buckets/get)
- [Cloud Storage: probar permisos IAM del bucket](https://docs.cloud.google.com/storage/docs/json_api/v1/buckets/testIamPermissions)
- [Cloud Storage: permisos requeridos para métodos JSON](https://docs.cloud.google.com/storage/docs/access-control/iam-json)
