# F0.10 R16 — Modelo de amenazas de consentimiento y privacidad

**Estado:** análisis estático para diseño; no es revisión de penetración ni aceptación de riesgo.
**Fecha/base:** 2026-11-07; worktree integration-security-hardening, rama recovery/integrate-backup, HEAD e4f2d5ed98a0a4b0f1a2625c93caa09f42ec6e4a.

## Activos y límites de confianza

- Identidad y perfil de cuenta adulta (Firebase Auth/Firestore).
- Datos de pasajero menor (actualmente formulario local; flujo backend nuevo alias/ID).
- Preferencias y evidencia de consentimiento (AsyncStorage/SecureStore, callable y Firestore).
- Ubicación actual y relaciones de match (matches/{matchId}/tracking/current).
- Telemetría/errores, datos enviados por SDK de anuncios y permisos del sistema operativo.
- Límites: entrada usuario/dispositivo no confiables; Auth; callable/Admin SDK; Firestore Rules; worker programado; SDK de terceros; almacenamiento local; configuración/runtime del build; soporte/eliminación.

## Controles existentes y limitaciones

- Callable autenticada, verificación de rol/owner, transacción y transiciones terminales; el Admin SDK es una frontera privilegiada distinta a Rules.
- Rules prohíben escritura cliente a passengerAuthorizations y acceso cliente a authorizationEvents (firestore.rules:421-432).
- Revocación usa cleanup pendiente y job horario (functions/index.js:450-452), pero el estado de preferencia del cliente y permisos de proveedor/sistema operativo no se unen automáticamente a ese job.
- El reporte R15 informa pruebas favorables del backend; esta auditoría R16 no las repitió y esas pruebas no demuestran consentimiento legal, seguridad global del cliente o integración extremo a extremo.

## Riesgo residual y condiciones de salida

F0.10 sigue BLOCKED hasta que Producto y Legal decidan alcance/datos/finalidades/representación/aviso/retención/proveedores y el equipo apruebe un contrato autoritativo integrado. Después: autorización específica de INC-2; verificación independiente y R1 para INC-3; C8 para INC-4; política y autorización de INC-6. No iniciar esos incrementos por este modelo.
